一个基于playwright的工具，爬取高等教育出版社旗下 新形态教材网书后部份资源文档（更新: 视频已经支持下载），网站调用了阿里云imm,渲染用的是金山文档，iframe嵌入，所以工具可以灵活修改用来爬取金山文档禁止下载的pdf ppt和word。pdf采用了滚动截图的处理，word由于是动态渲染的svg，用了新建canvas拷贝svg然后把canvas传回来 ppt和pdf同理，故不支持动画效果 只能拿到png   
感谢claude帮助支招 调试。项目基于java，初次运行maven会自动下载playwright依赖 chromium node环境  首次使用先运行cookie类获取cookie 抓包可以发现一部份书 里面 二维码里面url是/书id/1 2 3 4这种形式的，所以可以用for循环（代码逻辑已经实现）打开后会重定向到资源页面，但必须要求用户是登陆状态，所以必须先获取cookie
<br>
注意:
当抓取的时候 频繁出现错误 大概率是书需要激活码，此时可把setHeadless改成false 看到浏览器页面，如果弹出激活码，请输入
工具本身没有破解功能 只是批量下载抓取 想要完完整整抓取整本书(尤其是专业课书籍)必须具备书后面的激活码

26.4.17更新: 完善了视频 ppt的抓取逻辑，代码可被改造用于爬金山文档<br>
26.4.25更新： 新增h5动画爬取逻辑 建议启动web服务器，把保存下来的动画放上去用浏览器打开，可规避本地打开部份资源因cors失效而产生的问题<br>
26.9  小修小改: 增加了最后的重试逻辑，抓取的时候会因为各种原因存在失败的情况，程序新提供了一个开关（retry布尔)改成true 程序会自动看目录下面的空文件夹对应的序号 从而再次尝试提取

目前已知bug: 1、一些比如压缩包类的资源 程序目前无法自动获取 而网站只提示无法预览 没有给下载按钮，但抓包可以看到zip的文件路径（resource/info/byUser/xxxx接口返回的json）需要手动抠出来 复制下载
           2、提取h5动画的时候，由于是用浏览器缓存中导出，针对过大的资源（比如一些wasm）会失败，需要手动复制出过大的url 下载回来 丢到目录
